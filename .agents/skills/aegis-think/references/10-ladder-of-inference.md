# 推论阶梯

## 它逼你想什么

人从"看到的事实"到"得出的结论"，中间会连跳好几级，而且**自己意识不到跳了**。这个模型就是把跳过的台阶补回来。

## 五级台阶

```
5. 我采取行动        ← 我打算这么做
4. 我得出结论        ← 所以我认为…
3. 我加了假设        ← 因为我想当然地认为…
2. 我选了数据        ← 我只注意到了…
1. 观察到的数据      ← 实际发生的
```

## 怎么用

把自己的判断往下退到第 1 级，**检查第 3 级塞了什么假设**。

## 例子

> 用户说："做个贪吃蛇，浏览器能玩就行。"

- 5. 我打算：写一个单文件 HTML
- 4. 结论：他要一个本地能打开的游戏
- 3. **假设：他不会把它放到网上**
- 2. 我注意到的："浏览器能玩"
- 1. 事实：他说了"浏览器能玩就行"

**第 3 级的假设没被验证过。** 如果他要放到网上，就得考虑移动端、部署、甚至分享链接。

→ 该问的是："你是本地自己玩，还是要发给别人？"——**一句话就补上了这个假设**。

## 什么时候不该用

- 假设的成本极低，错了也无所谓
