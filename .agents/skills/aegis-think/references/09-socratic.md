# 苏格拉底追问

## 它逼你想什么

用户用的每个词，背后可能有一片模糊地带。**你不问，就会用自己脑子里的版本去填。**

## 怎么用

不提新问题，只对**用户已经说过的话**追问：

| 追问句式 | 用途 |
|---|---|
| "你说的 X，具体指什么？" | 拆开模糊名词 |
| "能举个例子吗？" | 把抽象落到具体 |
| "如果换成 Y 会怎样？" | 试探边界 |
| "这个和 Z 有区别吗？" | 建立区分 |

**一次只追一个词**，追到对方给出具体例子为止。

## 例子

> 用户："做个**最简**贪吃蛇。"

"最简"是什么？
- 最简 = 少写代码？
- 最简 = 少功能？
- 最简 = 打开就能看，不用理解？

追问："你说的最简，是指功能最少，还是指我交给你的时候你最省事？"

→ 可能的答案：**"我最省事"**。

那就完全变了一个方向：不是砍功能，是**别让他装任何东西**。

## 什么时候不该用

- 用户已经在用具体名词并给了例子
- 反复追问会让对方觉得被质疑（对熟人、对已经说得很清楚的人）
