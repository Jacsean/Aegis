# S4 · 展开（方案维度）


> 目的：把确认过的需求，变成**可看、可点、可评审**的方案。
> **本阶段核心：先给 HTML demo，再写代码。**

---

## 输入

- `docs/prd.md`（已由用户签字确认）
- `docs/INDEX.md`（避免与已有设计冲突）

---

## 动作清单

### 1. 架构设计

写 `docs/design/DESIGN.md`，必须包含：

| 章节 | 内容要求 |
|---|---|
| 模块划分 | 每个模块一句话说明**最本质的职责**（第一性原理）|
| 依赖方向 | 谁依赖谁，是否单向，有无循环 |
| 数据流 | 数据从哪来、经过哪、到哪去（配 Mermaid 或 ASCII 图）|
| 关键接口 | 函数/API 签名、输入输出、错误约定 |
| 状态管理 | 单一真相源在哪 |
| 错误路径 | 不只是 happy path |
| 扩展点 | 未来加功能从哪切 |

### 2. 前端：必须先出 HTML demo ⭐

> **这是 S4 最重要的产出。没有它，不许进 S6。**

**规则：**

- 每个「关键界面」（PRD 第 6 节列出）一个 demo 文件
- 放在 `docs/design/demo/` 下，命名 `01-<界面名>.html`
- **自包含单文件**：CSS/JS 内联，不依赖构建、不依赖网络
- 用户双击即可在浏览器打开看到效果
- 必须包含**真实交互**（可悬停、可点击、有动效），不是静态截图
- 每个 demo 文件顶部加注释，说明它对应 PRD 的哪个界面

**demo 必须覆盖的状态（缺一不可）：**

| 状态 | 为什么 |
|---|---|
| 正常态 | 基础展示 |
| 空状态 | 没有数据时什么样 |
| 加载态 | loading 反馈 |
| 错误态 | 出错怎么提示 |
| 交互反馈 | 悬停/点击/禁用的视觉变化 |

> 这五个状态是"交互流程确认"的实质内容。只画正常态的 demo 是假 demo。

### 3. 前端：写样式与交互规范

写 `docs/design/STYLE.md`：

- 色彩（主色/辅色/语义色：成功/警告/错误）
- 字体（字号阶梯、字重、行高）
- 间距（4/8 倍数体系）
- 圆角、阴影
- 组件清单（按钮/输入框/卡片/表格的规格）
- 交互反馈规则（何时 loading、何时 toast、何时 modal）
- 响应式断点

> STYLE.md 是 demo 的书面化。demo 先有，规范后有 —— 因为用户看着 demo 才好说"这个颜色再深点"。

### 4. 写 ADR（重大决策）

每个重大选择（框架、架构、协议、数据模型）一篇 ADR：
`docs/adr/ADR-0001-<标题>.md`

用 `99-reference/adr-schema.md` 的结构。
**「后果」一节必须写负面代价** —— 只写优点的 ADR 是宣传，不是决策记录。

### 5. 登记

- `docs/INDEX.md` 登记所有新文档
- 更新 `STATE.md`

## 人工确认

✅ **强制**，且必须是**看过 demo 之后**的确认。

确认时必须问的具体问题（不要问"满意吗"）：

```
design/demo/ 下共 N 个 demo，请打开查看：
- 01-xxx.html
- 02-xxx.html

请确认：
1. 整体视觉风格是否符合预期？（配色/字号/疏密）
2. 每个页面的元素是否齐全、位置是否合理？
3. 交互流程是否顺畅？（点击、悬停、状态切换）
4. 空/加载/错误三种状态的表现是否可以接受？

有需要调整的地方直接说，我改 demo 后再确认。
```

签字记录写入 `STATE.md`：
```
- S4 demo 确认：<日期> 用户查看 demo/01-xxx.html 后确认 ✅
```

## 常见失误

| 失误 | 后果 | 纠正 |
|---|---|---|
| **不给 demo 直接写代码** | 风格全靠猜，返工成本×10 | 铁律二：硬性禁止 |
| demo 只有正常态 | 交互流程没确认 | 必须 5 种状态 |
| demo 依赖 CDN / 需要构建 | 用户打不开 | 必须自包含单文件 |
| demo 是静态图 | 无法确认交互 | 必须有真实交互 |
| STYLE.md 先于 demo 写 | 抽象讨论，效率低 | demo 先行，规范提炼 |
| ADR 只写优点 | 无法判断代价 | 必写负面后果 |
| 架构图省略 | 用户看不懂设计 | 必须有图 |
| 用户说"你看着办" | 责任转移，风险后置 | 给出 2-3 个具体选项让选 |
