# 互斥穷尽（MECE）

## 它逼你想什么

你列的"可能的情况"，是不是**有重叠**（重复计算）或**有遗漏**（漏掉整块）？

## 怎么用

1. 把你想到的选项并排列出来
2. **查重叠**：有没有两项其实是一回事？
3. **查遗漏**：把所有选项加起来，是不是覆盖了全部可能？
4. 补上缺的那块

## 例子

> 用户在讨论"贪吃蛇要不要加功能"。

我列了：
- A. 加计分
- B. 加难度递增
- C. 加音效
- D. 加排行榜

**查遗漏**：这些都是"锦上添花"，但没列"基本可玩性"（方向响应、碰撞判定、重开）。

用 MECE 重列：
- 一、能不能玩（响应/碰撞/重开）
- 二、好不好玩（计分/难度/音效）
- 三、能不能分享（排行/存档）

→ 顺序错了：**必须先确认一，才轮到二和三**。

## 什么时候不该用

- 只是在发散想法，还没到要分类的时候
