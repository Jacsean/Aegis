# 六顶思维帽

## 它逼你想什么

同一件事，强制从六个互不重叠的角度各走一遍。**最常被跳过的是黑帽（哪里会坏）和黄帽（有什么价值）**——人一旦喜欢某个方案，就会只走红帽。

## 六顶帽子

| 帽 | 只看 | 一句话 |
|---|---|---|
| ⚪ 白帽 | 事实与数据 | 我现在确定知道什么？不确定什么？ |
| 🔴 红帽 | 直觉与情绪 | 我第一感觉是什么？用户会有什么感觉？ |
| ⚫ 黑帽 | 风险 | 哪里会坏？最坏会怎样？ |
| 🟡 黄帽 | 价值 | 好处是什么？为什么值得做？ |
| 🟢 绿帽 | 可能 | 还有别的做法吗？能不能不这么做也达到目的？ |
| 🔵 蓝帽 | 控制 | 现在该用哪顶帽？想完了吗？ |

## 怎么用

接任务时，**至少走黑帽和黄帽**——这两顶最能挖出"用户没说的事"：

- 黑帽：如果这个东西做出来没人用，最可能是因为什么？
- 黄帽：用户为什么值得为它花时间？

## 例子

> 用户说："做个贪吃蛇，浏览器能玩就行。"

- ⚫ 黑帽：他没提手机 → 在手机上打开会怎样？不能玩 → 那"能玩"这个要求对他就没达成
- 🟡 黄帽：他要的可能不是"游戏"，是"能立刻看到效果的演示" → 那"打开就能玩"比"功能齐全"更重要
- 🟢 绿帽：能不能干脆做成一个单文件 HTML，双击就开？→ 能做到，而且最省事

## 什么时候不该用

- 只需要一个角度就能判断时（改错别字不需要六顶帽）
