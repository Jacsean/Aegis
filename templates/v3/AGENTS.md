# AGENTS.md

> 给所有 AI agent 的唯一入口。**只写"读了才知道"的事**，不写能自己看出来的。

## 零、每次会话先读

1. 本文件
2. `preferences.md` —— 沟通偏好与工程约束，**始终生效**
3. `CORE-CHECKLIST.md` —— 收尾时要过的那几项（**打开只看第 1 层那四个字就够**）

> **按需才读的**：
> `CHECKLIST-GROWTH.md` —— 只在"发现了 4 个维度没覆盖的失效"时才打开记一行
> `EXTERNAL.md` —— 只在"要调用第三方能力"时才读（三头管控 + ≤2 个/任务）
> `constraints.md` —— 收尾时扫一眼（本项目自己的 ≤3 条）
> `AEGIS-分工.md` —— 换 agent 接手时，先读这个知道谁管什么

## 一、开工前必须做的一件事

接到新要求时，**先不要开始做**。用 `aegis-think` 技能把任务重想一遍：

```
1. 我理解你要的是：A（依据：你那句原话）
2. 我判断你真正需要的是：X
   依据：<用哪个模型看出来的>
   所以我打算这么做：<具体做法>
3. 还可能是 B / C；如果你更想要那个，我改
4. 请确认，或直接否掉第 2 条
```

**为什么**：用户说出口的是"他要的"，不是"他需要的"。差的这部分，是返工的主因。

**例外**：用户已明确到无可歧义（"把第 12 行的 typo 改掉"）时直接做。

## 二、每个决定都要留下痕迹

写进 `NOTES.md`，一条一次：

```markdown
## <日期> <一句话>
- 用了：<思维模型名>
- 判断：A
- 排除：B（理由）
- 我猜你可能还需要：D
- 什么情况说明我错了：<一句>
- 状态：待确认 / 已确认 / 已被推翻
```

**为什么**：下次会话（可能是别的 agent）读 `NOTES.md` 就能接上，不用重想。这比读整个项目便宜得多。

**上限**：`NOTES.md` 超过 200 行时，把已确认的老条目移到 `NOTES-ARCHIVE.md`，只留未闭合和最近的。

## 三、交付前自检

- [ ] 用户提的每一句要求，都做到了
- [ ] 我在 `NOTES.md` 里标"我猜你还需要"但没确认的，要么做了，要么明说了没做
- [ ] 交付说明里写了：怎么用、已知限制、下一步
- [ ] **没有为了显得完整而堆功能**

## 四、说"做完了"之前

必须贴出**实际验证过的输出**（跑通的截图/日志/命令结果）。"应该可以"不算完成。

## 五、什么时候该说"我不知道"

拿不准就问，不要猜着做，也不要编一个答案。**编造比说不知道的代价高一个数量级。**

## 附：这个文件故意不写什么

不写目录结构、不写技术栈说明、不写架构概览——**agent 自己能看出来的东西，写进来只是浪费上下文**。
