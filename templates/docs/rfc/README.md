# docs/align — 意图校准记录

> 本目录存放 S2 阶段的全部讨论产物。
> **它是 S3 写 PRD 的唯一依据。**

---

## 文件命名

| 文件 | 说明 |
|---|---|
| `CHECKLIST-<任务>-R1.md` | 第一轮（复述）问题清单 |
| `ALIGN-<任务>-R1.md` | 第一轮讨论记录与结论 |
| `CHECKLIST-<任务>-R2.md` | 第二轮（深层）问题清单 |
| `ALIGN-<任务>-R2.md` | 第二轮讨论记录与结论 |
| `ALIGN-<任务>.md` | **汇总：意图结论 + 边界 + 成功标准 + 签字** |

`<任务>` 与分支短名一致。例如分支 `feat/user-login` → `ALIGN-user-login.md`。

---

## 执行顺序（不可颠倒）

```
① make branch NAME=<任务短名>
② 写 CHECKLIST--R1 → 用户确认清单 → 逐条讨论 → 写 ALIGN-…-R1
③ 写 CHECKLIST--R2 → 用户确认清单 → 逐条讨论 → 写 ALIGN-…-R2
④ 写 ALIGN-<任务>.md 汇总 → 用户签字
⑤ make gate S2   →  PASS 才可进 S3
```

---

## 三条硬要求

1. **两轮不可合并** — 一轮问完所有问题不算两轮
2. **checklist 前置** — 先给清单，用户确认清单本身，再开始答
3. **日常语言** — 不懂技术的人也能直接回答；`gate.sh` 有技术词黑名单
