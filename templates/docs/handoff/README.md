# handoff 目录

每条记录一个文件：`H-<4位编号>-<短名>.md`

索引在上一级 `dev/HANDOFF.md`（一行一条）。

七要素与规则见 `.ai/99-reference/handoff-schema.md`。

## 记录模板

```markdown
# H-<编号> <标题>

- **时间**：<YYYY-MM-DD>
- **谁**：<人 / agent（会话 n）>
- **事件**：<做了什么，一句话，动词开头>
- **为什么这样处理**：<理由；〔推断〕/〔未知〕要标出来>
- **怎么处理的**：<具体做法 / 改了哪些文件>
- **试过什么**
  - ❌ <失败方案>：<为什么不行>
  - ✅ <成功方案>：<结果>
- **下一步 / 等谁**：<具体动作，或等谁回什么>
- **上接**：<H-xxxx（短名）／无>
- **下接**：<H-xxxx（短名）／暂无>
- **地点**：<事情发生或作用于哪里>（代码问题 → 文件:行号；需求变更 → 办公场所/客户现场；文档 → 文档+章节）
  commit 号不写这里，写在「怎么处理的」
```

**七要素一条都不能缺。**「试过什么」和「下一步」最容易漏，而它们恰恰是下一个人最需要的。

记录必含「**新词**」一行（铁律七）：本任务新词及词条状态，无则写「无」。
