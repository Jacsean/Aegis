## 1. 色彩

| 用途 | 变量 | 值 | 说明 |
|---|---|---|---|
| 主色 | `--c-primary` | `#2f6feb` | 主要按钮、链接、选中态 |
| 主色 hover | `--c-primary-hover` | `#1e5bd4` | 悬停加深 |
| 背景 | `--c-bg` | `#f6f7f9` | 页面底色 |
| 表面 | `--c-surface` | `#ffffff` | 卡片、面板 |
| 文字主 | `--c-text` | `#1a1d21` | 正文 |
| 文字次 | `--c-text-2` | `#5b6470` | 辅助说明 |
| 边框 | `--c-border` | `#e3e6ea` | 分割线、输入框边 |
| 成功 | `--c-success` | `#1a7f4b` | 完成态 |
| 警告 | `--c-warn` | `#b45309` | 待处理 |
| 错误 | `--c-error` | `#c0392b` | 失败、危险操作 |

**对比度**：正文与背景对比度 ≥ 4.5:1（WCAG AA）。

## 2. 字体

| 层级 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| xs | 12px | 400 | 1.5 | 标签、脚注 |
| sm | 13px | 400 | 1.6 | 辅助文字、按钮 |

## 4. 圆角与阴影

- 卡片圆角：`8px`；按钮/输入框：`6px`；标签胶囊：`999px`
- 卡片阴影：`0 1px 3px rgba(16,24,40,.08), 0 1px 2px rgba(16,24,40,.04)`

## 5. 组件清单

| 组件 | 规格要点 |
|---|---|
| 按钮（主） | 主色填充、白字、`8px 16px`、hover 加深、active 下沉 1px、disabled 变灰禁手 |
| 按钮（次） | 白底 + 边框 + 次要文字色，hover 背景转灰 |
| 输入框 | `1px` 边框，聚焦时主色描边 + 淡光环 |
| 卡片 | 白底 + 边框 + 阴影 + 8px 圆角 |
| 列表项 | 上下 12px 内边距，hover 背景 `#fafbfc`，分隔线 |
| 标签 | 12px 字、胶囊形、按语义着色 |
| 空态 | 图标 + 标题 + 说明 + 行动按钮，居中，上下 32px 留白 |
| 骨架屏 | 灰阶渐变 shimmer 动画，1.4s 循环 |

## 6. 交互反馈规则

| 触发 | 反馈 | 时长 |
|---|---|---|
| 悬停可点元素 | 背景/边框/颜色变化 | 150ms ease |
| 点击按钮 | 下沉 1px | 即时 |
| 数据请求 >300ms | 显示加载态 | 300ms 后出现 |
| 操作成功 | Toast 2 秒自动消失 | 2s |
| 操作失败 | 错误态或 Toast（红色） | 手动关闭 |
| 危险操作 | 二次确认 Modal | — |
| 表单校验失败 | 字段下方红字，失焦即校验 | 即时 |

**必须覆盖的 5 种状态**（每个界面）：
正常态 / 空状态 / 加载态 / 错误态 / 交互反馈（hover·active·disabled）

---

## 7. 响应式

| 断点 | 宽度 | 调整 |
|---|---|---|
| 桌面 | > 768px | 默认布局 |
| 平板 | 520–768px | 卡片间距缩小 |
| 手机 | < 520px | 单列、隐藏次要标签、内边距减小 |

---

## 8. 前端小贴士

- 状态切换集中在 `setState()` 一处，避免散落的显示/隐藏逻辑
- 用 `aria-pressed` / `aria-label` 保证键盘与读屏可用
- 过渡统一 150ms，避免动效过多分散注意
