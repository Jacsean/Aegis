# H-0001 建立 v1.0.0 基线

- **时间**：2026-10-20
- **谁**：agent（会话 18）+ 用户
- **事件**：把散装开发的 Aegis 整理成单基线 git 仓库，打 v1.0.0
- **为什么这样处理**：原来的历史是一次性倒入的假历史（4 次提交集中在同一分钟），无法用于回滚和追溯。用户要求「只要干净的历史」
- **怎么处理的**：合并为单条 baseline commit，message 写明 P0-P2 于 10-13 散装开发、P3-P7 于 10-20 补齐；打 tag v1.0.0；打 tar.gz 便携包（保留 `.git/` 与软链，不用 zip 因为 zip 会压平软链导致工作区有改动）
- **试过什么**
  - ❌ zip 打包：压平软链，解包后 git 报工作区有改动
  - ✅ tar.gz：保留符号链接与 `.git/`，解包后 `git status` 干净
- **下一步 / 等谁**：已完成。后续版本在此基线之上按分支 -> 合并 -> 打 tag 演进
- **上接**：无
- **下接**：H-0002（同日，加续接文档）
- **地点**：本机 git 仓库（无外部场所）；commit 与 tag 见「怎么处理的」
