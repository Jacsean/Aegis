# 文档索引

> 本文件只做索引：**有什么、在哪、干什么用、是什么角色**。
> 找不到东西时先查这里。
>
> **角色三种**：`真相源`（改这里，别处跟着变）｜`历史`（只增不改，记当时怎么想）｜`派生物`（由真相源生成，别手改）。
> **状态行**：设计文档头部必带 `> 状态：定稿｜暂定｜已作废→指向`。标「已作废」的禁止引用。
>
> **读的顺序**：`AGENTS.md` → `STATE.md` → 本页 → `CONCEPTS.md` 目录 → 当前阶段阶段卡。
